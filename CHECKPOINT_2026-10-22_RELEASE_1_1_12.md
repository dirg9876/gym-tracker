## Состав Выпуска

- Подготовленный номер1.1.12 сохранён; Android versionCode18, дата2026-10-22,
  native runtime1.1.0. Проверочные исправления входят в тот же логический выпуск.
- Без месячного плана автоматически формируется Push/Pull/Legs по всей завершённой
  истории. Свои виды тренировок остаются для ручного выбора; месячный план приоритетен.
- Сначала выбирается двигательный паттерн, затем знакомый вариант. Знакомые
  сгибания ног предпочитаются незнакомой технической румынской тяге.
- Незнакомое движение автоматического сплита сначала получает один проверочный
  подход. postCalibrationSets хранит отложенное количество рабочих целей.
- После RIR и техники добавляются только плановые цели, не выполненные подходы.
  При RIR0, нарушении техники или невыполненном probe расширения нет.
- Собственный вес может иметь короткий probe3повтора: проверяется его назначение,
  а не ещё не выполненный рабочий диапазон6повторов. При лёгком probe далее4повтора.
- Слишком тяжёлый подход снижает следующую цель с учётом ПОСЛЕДНЕЙ оценки;
  исходный тяжёлый подход не возвращает вес после последующего снижения.
- Противовес и секунды исключены из нового правила снижения внешнего веса.
  Снижение цифры противовеса не выдаётся за облегчение упражнения.
- Учитывается targetRir конкретного упражнения, не фиксированное2.
- После сохранения подхода экран явно перечитывает план: счётчик сразу1/3,
  а не устаревший зелёный1/1 до повторного открытия.
- Тяжёлые исторические синглы не превращаются в рабочую гипертрофийную тренировку.
  Отображаемая версия числовая1.1.12, без старого суффикса1.1.11a.

## Параметры И Совместимость

Сплит — продуктовая эвристика, не диагностика восстановления. Давность нагрузки
взвешивается exp(-ageDays/9); бицепс/трицепс/икры/пресс имеют вес0.5. К приоритету
добавляется9 при последнем занятии направления <2дней и4 при <3дней. При равенстве
порядок push/pull/legs. Используется только завершённая не будущая история.
Знакомство учитывает все сопоставимые рабочие5–30повторов (либо секунды), не синглы.
Количество сессий даёт min(6,2*sessions), недавнее знакомство <35дней ещё+2.
Объём: основные движения3подхода, часть аксессуаров2;4/5/6слотов для60/75/90мин.
Сила: обычно3–6; остальные основные8–12, аксессуары10–15; целевой RIR2.
Подбор собственного веса может быть короче. Веса на одну гантель, штанга >=20кг.

Сохранены Epley/RIR/EMA и ограничения прошлых выпусков. Модель не выдаёт e1RM
за фактический рекорд/разряд; гипертрофия не использует максимум как рабочий вес.
Подробности предыдущей модели: docs/TRAINING_MODEL.md. Backupv10 сохранён;
postCalibrationSets — необязательное дополнение схемы. Нативных API/зависимостей
не добавлено, runtime1.1.0 менять не требуется. Включение ИИ остаётся необязательным.
Контракт и provider шлюза не менялись; отдельного deploy Worker не потребовалось.
Платных AI-вызовов не делали, ключи/токены/лимит/журнал расходов не изменяли.
