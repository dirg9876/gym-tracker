# ИИ-тренер Gym-Beam

Обновлено 16 октября 2026. Личное приложение, облачный шлюз Cloudflare Workers Free.
ПК во время тренировки не нужен. Для ИИ требуется интернет; обычный дневник работает офлайн.

## Что уже работает

- Совет к следующему подходу: вес/повторы или секунды для удержания, с учётом записанных
  подходов и ваших оценок RIR/техники. Применяется только к черновику, а не к истории.
- Разбор завершённой тренировки через кнопку «Разбор тренировки» в отчёте.
- Следующая тренировка: упражнения, подходы, веса по известным результатам, целям
  и доступному оборудованию, с ориентиром на60–90мин.
- Три сценария: следующая по плану/истории, короткая офисная, план на месяц (4 недели).
  Офисная использует только собственный вес, турник, брусья и пол, без дополнительного
  веса/тренажёров, до9 подходов. Обычная тренировка ориентирована на60–90мин.
- Месячный план содержит расписание, несколько тренировочных шаблонов и фокус каждой
  недели. Он сохраняется после перезапуска и входит в экспорт. Завершённые плановые
  занятия отмечаются зелёным; офисная тренировка не продвигает месячный план.
- Короткие сообщения во время занятия: заменить занятый тренажёр, сменить мышцы сегодня,
  уменьшить объём, уточнить рекомендацию. Замена затрагивает только оставшуюся часть.
- Во время занятия есть быстрые команды «Тренажёр занят», «Другие мышцы сегодня»,
  «Снизить нагрузку»; можно написать свою короткую просьбу.
- Любой план сначала открывается для проверки/редактирования. Без подтверждения
  тренировку не создаём, подходы не записываем, историю не меняем.

## На телефоне

1. Перед обновлением сделайте внешний экспорт прогресса через Главная -> резервная копия.
2. Установите `artifacts/apk/verified/gym-beam-ai-coach.apk` (versionCode5). Не удаляйте
   установленное приложение, если Android отказал в обновлении: сначала нужен backup.
   Этот APK подписан тем же локальным сертификатом, что gym-beam-autoconnect.apk;
   с исходным EAS APK сертификат отличается. Подробности в api-server/PHONE_SETUP.md.
3. Подключение повторно импортировать не требуется при обычном обновлении поверх
   предыдущего локального APK. У сохранённого подключения кнопка «Шлюз подключён»
   неактивна; изменение адреса или токена снова открывает действие подключения.
   Единственный тумблер «ИИ-тренер» включает советы и отправку контекста. При первом
   включении подтвердите передачу данных. Разрешение запоминается; выключение ИИ
   прекращает отправку и отменяет текущие запросы. «Забыть подключение» отзывает доступ.
   Сохраните цель, оборудование и дни в неделю. Исключений нет; длительность отдельно
   выбирать не нужно. Зелёная молния означает, что тренер ON.
4. Главная -> «Начать тренировку с ИИ» -> выберите один из3 сценариев. Для следующей
   тренировки учитывается следующий невыполненный пункт месячного плана, если он есть,
   и фактическая история. Для офисной доступны только упражнения с собственным весом.
   Можно добавить пожелания на сегодня, затем «Составить тренировку».
5. Готовый план появится на том же экране со всеми весами. Раскройте упражнение для
   изменения веса/повторов/подходов, затем «Начать эту тренировку», без промежуточных окон.
   Без истории назначается лёгкий старт: первый подход подбирает нагрузку. Отметьте запас
   повторений и технику после него; будущие веса скорректируются, запись подхода не меняется.
6. Во время занятия «Написать тренеру»: введите до300 символов или выберите быструю команду
   и отправьте. Уточняйте упражнение и желаемую группу мышц, если просьба неоднозначна.
7. Проверьте новый оставшийся план и нажмите «Применить изменения». При изменении
   дневника/профиля старое предложение отклоняется: запросите актуальное.
8. По окончании завершите тренировку обычной кнопкой. В отчёте доступен разбор; тренировку
   можно сохранить как редактируемый вид для повторения. Автоматический экспорт сохраняется.
9. Для месяца: сценарий «На месяц» -> «Составить месячный план» -> просмотр на том же
   экране -> «Сохранить месячный план». Далее «Следующая тренировка по плану»: ИИ адаптирует
   конкретное занятие к свежим результатам. Вес по неделям автоматически не увеличивается.
   Сохранённый месяц также открывается из настроек тренера и доступен для чтения при OFF.
   Можно заменить/удалить сам план, сохранив историю; после выполнения4недель составить новый.

Примеры коротких сообщений: «Вертикальный блок занят, замени только его»,
«Сегодня хочу ноги вместо спины», «Осталось20 минут, сократи оставшуюся тренировку».
При боли не просите ИИ подобрать способ продолжать болезненное упражнение.

## Данные и ограничения

Тренер видит до12 последних завершённых тренировок плюс текущую, до160 недавних подходов,
каталог до120 упражнений, последние3 шаблона, профиль целей/оборудования, указанные пол/вес,
текущий невыполненный черновик. При корректировке также получает оставшийся план и последние
сообщения. Недостающие данные не считаются положительной оценкой техники или запаса.
Для незнакомого упражнения предлагается конкретный лёгкий старт: штанга с грифом 20 кг,
одна гантель 2.5 кг, тренажёр 5 кг, другое отягощение 2.5 кг; собственный вес без добавления.
Это не измерение вашей силы и не гарантия безопасности: недоступную/слишком тяжёлую нагрузку
нужно уменьшить или заменить упражнение. Вес другого упражнения не переносится.
После первого подхода RIR 4+ и сохранённая техника дают +2.5 кг на будущие подходы;
RIR 0–1 или нарушение техники уменьшают нагрузку. Если вес уже минимальный, уменьшаются
повторы; с собственным весом регулируются повторы. При боли занятие нужно остановить.
Цель «Мышцы» применяется после «Сохранить параметры»: тренер ориентируется на рост мышц,
умеренный запас и постепенный объём, не на максимальный спортивный разряд.

Обновления без удаления приложения описаны в `artifacts/gym-tracker-mobile/UPDATES.md`.

Диалог хранится только в памяти экрана, не включается в экспорт прогресса и не гарантирует
память после закрытия/перезапуска. Для постоянных предпочтений используйте параметры тренера.
Выполненные подходы и принятый активный план сохраняются отдельно как обычный прогресс.
OpenAI вызывается с store=false, без web tools и автоматических повторов. Это не обещание
нулевого хранения со стороны провайдера. Ключи/полные резервные копии контекстом не отправляются.

Это помощник по записанным данным, не очный тренер или врач. Он не видит технику на видео,
не диагностирует травмы и не меняет программу без подтверждения. Месяц является блоком
на4недели с относительными днями недели, а не обязательным календарём с уведомлениями.
Ответы нужно проверять; измеримые ограничения проверяются приложением и шлюзом.

## Научная Основа

В каждый запрос включается проверенный набор принципов из
[позиции ACSM2026](https://pubmed.ncbi.nlm.nih.gov/41843416/): постепенное развитие нагрузки,
соответствие цели, учёт недельного объёма, отсутствие обязательного отказа в каждом подходе
и допустимость разного оборудования. Это обзор исследований здоровых взрослых, не
назначение при заболеваниях. Числа из исследований не превращаются в обязательный
минимум для новичка. Ограничения продукта (шаг повышения2,5кг, лимит подходов по времени)
не выдаются за клинические нормативы. Ссылка на источник доступна под ответом в диалоге.
Тренер не ищет новые исследования в интернете при каждом сообщении и не должен выдумывать ссылки.

## Модели и Бюджет

Сейчас на всех этапах работает `gpt-6-luna`, reasoning=none, Standard, до2400 outputtokens
для обычных советов и до6000 для месячного плана. Весь лимит учитывается в резерве до вызова.
Модель и тариф автоматически не повышаются. Бюджет шлюза остаётся $5 за календарный месяц UTC;
он относится только к этому шлюзу, а не к другим расходам вашего OpenAI-аккаунта.
Неизвестный исход запроса сохраняет резерв до разбирательства, а не обнуляет его.

Предлагаемое дальнейшее распределение (ещё НЕ включено):

| Этап | Модель-кандидат | Причина |
| --- | --- | --- |
| Вес следующего подхода, короткая замена, обычный план | Luna | Быстро и дёшево; ограничения проверяет код |
| Еженедельный обзор, застой, пересмотр программы | GPT6.1Sol, low | Кандидат для более сложного анализа, сначала сравнительный тест |
| Обычная тренировка | Без Astra и постоянного web search | Для текущей задачи не оправдывать расход без измеренной пользы |

Проверенные цены Standard за1M токенов: [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)
$0,10 input/$0,50 output; [GPT6.1Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)
$2 input/$10 output. У Sol6.1 нет reasoning=none; reasoningtokens также влияют на стоимость.
При условных8000 input+1000 output один запрос Luna=$0,0013, Sol=$0,026 без кэша.
Это пример, не обещание месячного расхода: фактические длина истории/ответа и reasoning меняются.
Ни одна модель не становится профессиональным тренером только благодаря своему названию.

193 автоматических теста прошли. Проверки включают AndroidUI, историю из12 плановых
занятий за4недели, backupv8/import1..8,
office/month constraints, stale-context и бюджет. Два реальных ответа новых сценариев
на вымышленных данных (офис/месяц) прошли, стоимость проверки $0,0014358. До этого отдельно
проверены замена тренажёра/мышц ($0,0007126). Автоматических повторов0.
