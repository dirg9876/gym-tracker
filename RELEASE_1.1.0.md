# Gym-Beam 1.1.0

Android versionCode 6. Устанавливайте APK поверх последней локальной версии, не удаляя приложение. Перед первым обновлением сделайте внешний экспорт прогресса.

- Обновления интерфейса/логики через Expo Update; проверка значком загрузки на Главной. Изменения native-модулей по-прежнему требуют нового APK.
- В ИИ-планах уже заполнены веса всех подходов. Без истории назначается лёгкий подборочный подход; после оценки запаса и техники корректируются следующие подходы, не фактическая запись.
- Веса/повторы/число подходов можно менять степперами. После выбора другого упражнения приложение остаётся на нём до выполнения его подходов.
- Цель «Мышцы» учитывается как рост мышц, а не погоня за максимальным разрядом. После выбора цели нажмите «Сохранить параметры».
- Один экран для следующей/офисной тренировки и плана месяца, без промежуточного редактора и лишнего подтверждения запуска.

205 тестов PASS, typecheck PASS. На эмуляторе проверены установка поверх старой версии, применение настоящей OTA, подбор нагрузки и сохранность прогресса. Ключи и персональные копии в APK/исходники не включены.

SHA256 APK: `1CE75ADDEAB8FA0EC96F09F4CC3E28636BCBB8E8AFC2D8C89AE620F5A20C50A1`.

Если Android сообщает о несовместимой подписи, не удаляйте приложение без проверенной внешней копии: исходный EAS APK и локальные APK подписаны разными ключами.
