# Gym-Beam 1.1.7

- Архив упражнений убран. Записи без подходов можно удалить полностью; для упражнений с историей нужно выбрать замену.
- Замена на существующее или новое упражнение переносит подходы, рекорды, виды тренировок, текущие и месячные планы. Уровень пересчитывается по выбранному упражнению.
- Перенос защищён от смешивания оборудования, секунд и повторов, противовеса и разного числа гантелей. При объединении сохраняются реальные веса, оценки подходов и снимки массы тела.
- Старые архивные записи без результатов удаляются автоматически. Записи с историей возвращаются в каталог с предложением выбрать замену, без потери результатов.
- Сохранение упражнения теперь в шапке редактора: кнопка доступна и с открытой клавиатурой.

Обновление совместимо с native runtime1.1.0. Не удаляйте приложение и не очищайте его данные. После публикации: Обновления > Проверить обновления > Применить обновление.
