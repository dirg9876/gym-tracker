# Gym-Beam 1.1.1

- Выбор категории при создании упражнения: штанга, гантели, собственный вес, тренажёры, другое.
- Тоннаж упражнений с собственным весом учитывает массу тела и дополнительную нагрузку, в том числе в истории. В старых записях без снимка массы используется текущий вес профиля с пометкой «расчётный». Укажите свой вес в профиле, чтобы расчёт был полным.
- Уровень определяется результатами любых трёх разных упражнений. Повторы и секунды учитываются в своих единицах; условные ориентиры не являются официальными спортивными разрядами.
- Окно «Что нового» после обновления: один раз после прочтения, без вмешательства в активную тренировку. Повторное открытие в разделе «Обновления».
- Следующие готовые выпуски получают новый номер версии и описание изменений.

## Обновление

Для APK 1.1.0 с поддержкой OTA: откройте «Обновления», нажмите «Проверить обновления», затем «Применить обновление». Переустанавливать приложение не требуется; применяйте обновление после завершения тренировки. Также можно установить APK 1.1.1 поверх предыдущего локального APK с той же подписью, без удаления приложения.

Перед заменой старой сборки сохраните внешний экспорт прогресса. Если Android сообщает о несовпадении подписи, не удаляйте приложение ради установки: сначала проверьте резервную копию и совместимость сборок.
