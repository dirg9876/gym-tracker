# Математическая модель Gym-Beam 1.1.9

Версия алгоритма `epley-rir-ema-v1`. Расчёт локальный и детерминированный,
не требует ИИ/интернета и не изменяет выполненные подходы, рекорды и уровни.
Основание: согласованный пользователем документ Gym_Tracker_algorithm_prediction_
2026-10-21.md. Документ используется как техническое предложение, не новый журнал.

## Расчёт

Три независимых модуля в lib/ai-coach/src/training-model:

- StrengthEstimator: `e1RM = W * (1 + (reps + RIR) / 30)`.
- RepPredictor: `W = S / (1 + (reps + RIR + F) / 30)`;
  `reps = max(0, 30 * (S / W - 1) - RIR - F)`.
- ProgressionController: численный прогноз ограничен правилами прогрессии,
  округляется вниз по сетке оборудования; минимум штанги20кг.

Для измерения нужны2-10целых выполненных повторений, известный RIR0-3,
положительный вес и сохранённая техника. Синглы, неизвестные/плохие оценки,
высокие повторы и удержания не являются измерениями силы для этой формулы.
Каждое упражнение, категория, способ нагрузки и число гантелей рассматриваются
отдельно. Гантели считаются в весе ОДНОЙ гантели. Тренажёр сопоставим только
с тем же тренажёром; приложение пока не различает модели тренажёров с одним ID.
Собственный вес (включая0кг дополнительного), противовес, секунды и «Другое»:
формула не применяется; остаются обычные правила/калибровка, без деления на0.

Оценка обновляется по ПЕРВОМУ подходящему подходу завершённого занятия:
`S = 0.8 * S_previous + 0.2 * e1RM_session`. Остальные подходы не тянут
долгосрочную силу вниз из-за утомления. История измерений90дней; разрыв>28дней
начинает новую оценку, отсутствие свежего измерения28дней запрещает её применение.
Сегодняшний первый качественный подход даёт отдельную временную оценку сегодня,
но не записывает новый долгосрочный результат до завершения тренировки.

`F = beta * (номер подхода - 1)`. beta — медиана снижения `(reps + RIR)`
при одинаковом весе на подход; минимум3сравнения на2занятиях. beta ограничена0-3
как продуктовая эвристика. Без данных beta=null: никакой выдуманнойbeta1.
Сон, отдых и восстановление из времени ввода записей не реконструируются.

## Прогрессия и роль ИИ

Сначала повторы внутри диапазона. Прибавка веса — только после двух полных
недавних занятий на одном весе, верхней границе повторов и с RIR>=max(2,targetRir)
и сохранённой техникой во всех подходах. Автоматическая прибавка<=2.5кг,
больший шаг требует решения пользователя. Эти пороги — настройки продукта,
не универсальные физиологические законы. Отказ/пропущенные оценки не разрешают
увеличение; нарушение техники требует коррекции. Модель может ограничить
разрешённую цель, но не может сама разрешить прибавку. Известный одиночный
максимум без рабочих подходов не заменяет калибровку.

Экран тренировки показывает расчёт и кнопку явного применения, обычные
регуляторы остаются доступны. Подробности прогноза сворачиваются. В истории
модель включена в локальный разбор. Новые AI планы получают численные цели
локального контроллера, включая дальнейшие подходы при определённойbeta.
Новые next_set ответы нормализуются к локальному nextSetTarget на шлюзе И клиенте;
устаревшие ответы проверяются по fingerprint/revision. Старые клиенты без новых
полей поддержаны. ИИ объясняет, замечает ограничения, выбирает упражнения и
предлагает персональные изменения для подтверждения; численные значения не
передаются на его усмотрение. Ручные изменения пользователя сохраняются.

## Проверка качества

Walk-forward: для первого качественного подхода занятия прогноз строится
по ранее ЗАВЕРШЁННЫМ занятиям, затем записывается ошибка и обновляется EMA.
Показываются MAE повторов и число проверок. Это УСЛОВНЫЙ прогноз при записанном
RIR подхода, а не доказанная точность будущего назначения. При пересекающихся
по времени занятиях проверка пропускается. Для старого отчёта будущая история
исключается. MAE_RIR=null: старые журналы не содержат достоверно сохранённого
назначенного RIR каждого выполненного подхода. Нельзя подменять его текущими
настройками или рисовать фиктивную метрику.

## Ограничения и следующий этап

e1RM — оценка, не фактический рекорд/норматив и не измерение мышечного роста.
RIR/техника субъективны и могут переноситься между подходами. Уровни считают
только реальные выполненные веса. Ошибка1-2повтора — цель исследования,
НЕ обещание. Нет вероятностей успеха, доверительного интервала, фильтра Калмана,
автоматического диагноза усталости, опроса сна/болезненности и автоадаптации
объёма. Сначала нужны достоверные назначенные цели и больше сопоставимых данных.

Научная оговорка: применимость RIR и формул зависит от упражнения/условий;
исследование https://pubmed.ncbi.nlm.nih.gov/38595310/ рассматривает жим, а не
доказывает универсальность этой конкретной реализации. alpha/beta/сроки/ограничения
выше — явные начальные продуктовые параметры, не клиническая модель.
