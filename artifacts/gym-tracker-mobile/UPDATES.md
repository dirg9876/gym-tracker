# Обновления Gym-Beam

## На телефоне

1. Установите Gym-Beam 1.1.0 (Android versionCode 6) поверх последнего локального APK. Не удаляйте приложение. Перед первым обновлением сделайте экспорт прогресса в отдельную папку телефона.
2. Последующие изменения JavaScript, интерфейса и изображений приходят через Expo Update. При запуске приложение проверяет канал `production`; загруженное обновление применяется при следующем запуске.
3. Для ручной проверки откройте значок загрузки в верхней части Главной. Нажмите «Проверить обновления», затем «Применить обновление». Во время активной тренировки принудительное применение заблокировано.
4. Новый Android-модуль, изменение разрешений или несовместимый runtime требуют нового APK. Его устанавливают поверх текущего, без удаления, с той же подписью и увеличенным versionCode.

Старые APK versionCode 1–5 не содержат Expo Update и сами получить этот механизм не могут. Поэтому APK 6 нужно установить один раз. Если Android сообщает о конфликте подписи, не удаляйте приложение: сначала проверьте экспорт и сертификаты. Исходная EAS-сборка и локальные APK имеют разные подписи; обойти проверку Android без исходного ключа нельзя.

## Публикация Изменений

Проект EAS: `@dirg9508/gym-tracker-mobile`, id `dabd3128-415f-4a2f-8c73-3b0a52585149`.
Канал и ветка EAS: `production`. Git-ветка исходников: `master` (это независимые имена).
Runtime: `1.1.0`, политика `appVersion`. При изменении native-зависимостей/плагинов/разрешений увеличивайте `expo.version` и `android.versionCode`, выпускайте новый APK. Не публикуйте несовместимый JS в старый runtime.

Из `artifacts/gym-tracker-mobile`, после тестов и коммита:

```powershell
pnpm dlx eas-cli@16.32.0 update --channel production --platform android --environment production --message "Описание изменений" --non-interactive
```

Не включайте платный тариф автоматически. Для личного устройства используйте доступную квоту EAS Update; при исчерпании квоты публикация должна остановиться, а встроенная/offline-версия продолжит работать.

Подписанный локальный APK:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-17.0.18.8-hotspot'
$env:ANDROID_HOME = 'C:\gymbeam\artifacts\android-sdk'
.\scripts\build-release.ps1
```

Скрипт требует существующий локальный ключ из `artifacts/apk/debug.keystore` и проверяет его SHA256; ключ не включён в Git. Он не генерирует новую подпись при отсутствии старой. Сертификат APK: `dfdcf05447cf713727f87f653a702649e4bf0ba8ff9598b294d0ac26a264814a`.
EAS Build использовал другой ключ: не заменяйте этим способом локальный APK без предварительной настройки того же ключа. EAS Update ключ Android не меняет.

## Проверка Сохранности

История, шаблоны, план месяца и черновик подхода хранятся отдельно от JS. Перед ручной перезагрузкой прогресс проверяется и создаётся внутренняя копия. Это не заменяет внешний экспорт. На эмуляторе проверяйте `adb install -r`, сравнивайте экспорт до/после и отдельно проверяйте загрузку OTA.

Документация: https://docs.expo.dev/eas-update/getting-started/ и https://docs.expo.dev/eas-update/runtime-versions/.
