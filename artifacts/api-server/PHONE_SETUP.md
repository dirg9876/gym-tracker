# Gym-Beam на телефоне

Обновлено 16 октября 2026, Europe/Moscow. Личное Android-приложение.

Актуальный APK: `artifacts/apk/verified/gym-beam-ai-coach.apk`, versionCode5.
Добавлены зелёная молния, запуск ИИ с Главной и короткие сообщения во время занятия.
Инструкция по новым сценариям: [AI_COACH_GUIDE.md](../../AI_COACH_GUIDE.md).
Повторный «Подключить шлюз» с теми же адресом/токеном больше не выключает тренера.

## Подключить облачного тренера

Проверенный адрес: https://gym-beam-coach.dirg9876.workers.dev

Домашний ПК, USB, одинаковый Wi-Fi и локальный сервер больше не нужны.
Для ИИ нужен интернет на телефоне. Обычный дневник работает без сети и ИИ.
Workers Free подтверждён владельцем; платный тариф не включался. SQLite Durable
Object сохраняет журнал расходов. При исчерпании бесплатных квот ИИ может временно
перестать отвечать. [Квоты Cloudflare](https://developers.cloudflare.com/durable-objects/platform/pricing/).

1. Установите новый APK gym-beam-ai-coach.apk по инструкции ниже.
2. Перенесите на свой телефон личный файл
   C:\gymbeam\artifacts\api-server\.coach-data\gym-beam-coach-connection.json
   через USB или защищённое личное хранилище. Не публикуйте этот файл: он содержит
   токен доступа к вашему платному ИИ, но НЕ ключ OpenAI.
3. Откройте Главная -> молния -> ИИ-тренер -> «Импорт подключения», выберите
   gym-beam-coach-connection.json и подтвердите адрес кнопкой «Подключить».
   Адрес и токен подставятся автоматически. Должны появиться gpt-6-luna и расходы.
4. Включите единственный тумблер «ИИ-тренер» и при первом включении подтвердите передачу
   контекста тренировок через Cloudflare в OpenAI. Отдельного переключателя данных нет.
5. Задайте цель, дни в неделю и оборудование. Сохраните. Исключений нет,
   обычная тренировка ориентирована на60–90мин; офисный сценарий отдельный короткий.
6. Удалите временную копию файла подключения из общедоступной папки телефона.
   Приватный оригинал на ПК можно оставить для нового телефона или переустановки.

Подключение не отправляет историю модели. Запросы к ИИ только по кнопке.
На эмуляторе HTTPS проверен без локального сервера и ADB reverse; согласие и ИИ
оставлены выключенными. Автоматические проверки выполнялись на эмуляторе;
пользователь отдельно сообщил об успешном подключении своего телефона.
/healthz в браузере проверяет связь бесплатно и не вызывает модель.

Разовый импорт нужен только на новом устройстве или после удаления данных приложения.
Далее подключение восстанавливается автоматически после перезапуска и обновления APK:
токен зашифрован через Android Keystore, адрес заполнен по умолчанию. Выключенный
ИИ остаётся выключенным. Токен не вшит в APK и не входит в резервную копию прогресса.

## Где найти адрес и токен

- Адрес: https://gym-beam-coach.dirg9876.workers.dev. Уже заполнен в приложении.
  Также виден в Cloudflare -> Workers & Pages -> gym-beam-coach.
- Токен: C:\gymbeam\artifacts\api-server\.coach-data\owner-token; оба значения
  также есть в личном gym-beam-coach-connection.json в той же папке.
- На телефоне после импорта: Главная -> молния -> ИИ-тренер. Адрес виден,
  токен скрыт; кнопка с глазом показывает его. Оба поля можно редактировать,
  затем нажать «Подключить шлюз». Произвольный новый токен не сработает: значение
  должно совпадать с серверным AI_COACH_OWNER_TOKEN.
- Выключатель ИИ сохраняет подключение. «Забыть подключение» удаляет токен с
  устройства и выключает согласие/ИИ, но не удаляет тренировки. После этого нужен
  повторный импорт. Изменение адреса требует нового согласия на отправку данных.
- Для обновления показанного расхода нажмите круговую стрелку рядом с расходами.

Ключ OPENAI_API_KEY на телефоне не нужен и туда не вводится.

## APK и прогресс

1. В старой версии экспортируйте прогресс во внешнюю папку телефона. Проверьте,
   что JSON существует вне приложения, до удаления или переустановки.
2. Новый APK: C:\gymbeam\artifacts\apk\verified\gym-beam-ai-coach.apk,
   versionCode5, arm64-v8a/x86_64, Android7+. Это полноценная native сборка
   с SecureStore, не прежний JS repack. Старый gym-tracker-tested.apk ещё RAM-only.
3. Подпись совпадает с прежним локальным проверенным APK: его можно обновить
   поверх, без удаления данных. Debug-подпись отличается от исходной EAS-сборки.
   Если обновление отклонено,
   не удаляйте старую версию без проверенной внешней копии. Для бесшовных обновлений
   ещё нужны исходный release key и увеличенный versionCode.
4. При необходимости импортируйте копию. Backup1..8 поддерживаются; импорт
   выключает ИИ и не переносит credentials или соединение.
5. Выберите на телефоне папку автокопий заново. Разрешение Android на папку
   эмулятора не переносится. Телефон и эмулятор автоматически не синхронизируются.

Проверено на эмуляторе: импорт файла, masked token, восстановление после force-stop
и обновления, forget/reimport, обновление расходов после cold start. Прогресс
2тренировки/8подходов/31упражнение полностью совпал до и после. 134mobile +12Node
+8workerd =154теста и fullworkspace typecheck прошли. Новых платных вызовов не было.
Физический телефон ещё не проверялся.

## Использовать тренера

- В тренировке выберите упражнение, отмечайте RIR и технику. «Совет для следующего
  подхода» предлагает значения; применение меняет только черновик. Выполненный
  подход записывается обычной кнопкой «Добавить подход».
- Для нового занятия на Главной нажмите «Начать тренировку с ИИ». План с числовыми
  весами появляется на том же экране; веса и подходы можно менять до запуска.
  Первое неизвестное упражнение получает подборочный подход: после него отметьте
  запас и технику, чтобы скорректировать следующие подходы. В отчёте доступен разбор.
- Выключение ИИ не удаляет историю и планы. Обработанный запрос может быть оплачен
  даже после отмены ожидания. Сценарий «На месяц» сохраняет четыре недели; следующая
  тренировка учитывает фактическую историю. ИИ не работает сам по расписанию.
- ИИ может ошибаться; небольшой тест не заменяет оценку тренера или врача.

## Расходы

Лимит шлюза: максимум $5 за календарный месяц UTC. Это не подписка: учитываются
API-вызовы. Локальные расходы перенесены, не обнулены. После семи реальных тестовых
вызовов учтено $0.0022081, резерв0. Последний облачный тест стоил $0.000315;
повтор контекста вернулся из кэша без нового расхода.

Лимит относится к этому шлюзу по настроенным ценам, не к сторонним приложениям
того же API-проекта, налогам или хостингу. Отдельный проект API предпочтителен.
При изменении цен нужна проверка серверной конфигурации.
[Модель и цены OpenAI](https://developers.openai.com/api/docs/models/gpt-6-luna).
