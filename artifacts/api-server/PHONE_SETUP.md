# Gym-Beam На Телефоне

Личное Android-приложение. Установочный файл находится в
[GitHub Releases](https://github.com/dirg9876/gym-tracker/releases).
Не используйте старые тестовые APK из локальных папок как актуальный выпуск.

## Установка И Обновление

1. В установленной версии экспортируйте прогресс во внешнюю папку телефона
   и проверьте, что JSON доступен вне приложения.
2. Скачайте APK нужного выпуска Gym-Beam и установите поверх приложения,
   без удаления. При конфликте подписи остановитесь: удаление приложения
   стирает локальные данные. Нужен APK с тем же сертификатом либо проверенный
   внешний экспорт перед переносом.
3. Совместимые обновления логики и интерфейса доступны через значок обновлений
   на Главной: «Проверить обновления», затем «Применить обновление».
   Не прерывайте активную тренировку. Изменения native-модулей требуют нового APK.
4. При первом запуске на новом устройстве импортируйте прогресс и заново выберите
   папку автоматических копий. Разрешение на папку другого устройства не переносится.

Подробности: [обновления APK и OTA](../gym-tracker-mobile/UPDATES.md).
Телефон и эмулятор автоматически не синхронизируют историю.

## Подключение Тренера

Адрес шлюза: `https://gym-beam-coach.dirg9876.workers.dev`.
Он уже заполнен в приложении. Для ИИ требуется интернет на телефоне;
домашний ПК, USB и локальный сервер во время занятия не нужны.

1. Для первого подключения перенесите на телефон личный файл
   `C:\gymbeam\artifacts\api-server\.coach-data\gym-beam-coach-connection.json`
   через USB или защищённое личное хранилище. Файл содержит секретный токен
   доступа к шлюзу: не отправляйте его в чат и не публикуйте.
2. Главная -> молния -> «Импорт подключения». Выберите файл и подтвердите адрес.
   Адрес и токен подставятся автоматически. Само подключение не вызывает модель.
3. Включите «ИИ-тренер» и подтвердите отправку контекста шлюзу и провайдеру.
   Зелёная молния показывает включённого тренера. При сохранённом подключении
   кнопка «Шлюз подключён» неактивна, пока вы не измените адрес или токен.
4. Задайте цель, дни в неделю и оборудование, затем «Сохранить параметры».
5. Удалите временную копию файла подключения из общедоступной папки телефона.
   Приватный оригинал сохраните для нового устройства.

Разовый импорт подключения не нужен после обычного обновления поверх:
токен сохраняется через Android Keystore. Он не вшит в APK и не входит
в резервную копию прогресса. Импорт прогресса выключает ИИ, а не выдаёт доступ
к платному шлюзу. «Забыть подключение» удаляет токен с устройства, но не тренировки.

## Где Найти Адрес И Токен

- Адрес виден в настройках тренера и в Cloudflare -> Workers & Pages ->
  `gym-beam-coach`.
- Токен владельца: приватный файл
  `C:\gymbeam\artifacts\api-server\.coach-data\owner-token`.
  Адрес и токен также есть в личном файле подключения из той же папки.
- На телефоне адрес и токен можно изменить в разделе с молнией; токен скрыт,
  кнопка с глазом показывает его. Новый токен должен совпадать с серверным
  `AI_COACH_OWNER_TOKEN`, а не быть произвольной строкой.
- Ключ `OPENAI_API_KEY` на телефоне не нужен. Не вводите его вместо токена шлюза.

## Использование И Расходы

На Главной нажмите «Начать тренировку»: готовое занятие рассчитывает приложение,
ИИ при включении проверяет его на том же экране. Проверка расходует API-бюджет,
но её можно не ждать. Принять план или начать самостоятельно можно без ответа ИИ.
Во время занятия доступны советы и короткие сообщения, после завершения разбор.
Подробно: [возможности тренера](../../AI_COACH_GUIDE.md).

Расход, резерв и лимит обновляются круговой стрелкой в настройках тренера.
Лимит шлюза не выше $5 за календарный месяц UTC, по настроенным серверным ценам;
он не покрывает другие приложения API-аккаунта, налоги и хостинг. Недоступность
ИИ не блокирует дневник. Публикация уже установленного OTA не требует включённого ПК.
