# Шлюз ИИ Gym-Beam

Основное подключение телефона использует облачный Worker:
`https://gym-beam-coach.dirg9876.workers.dev`.
ПК во время тренировки не требуется. [Инструкция для телефона](PHONE_SETUP.md).

Этот каталог содержит общую логику тренера и необязательный Node-шлюз.
Тренировки хранятся на Android-устройстве; шлюз не является сервером дневника.

## Архитектура

`src/coach/core.ts`, `provider.ts` и `ledgerCore.ts` используются Node и Worker.
Node хранит бюджет в SQLite; облако использует SQLite Durable Object.
Production использует один объект `owner-v1` с постоянным журналом расходов.
Инструкция публикации: [Worker](../ai-coach-worker/README.md).

После переноса в облако локальный запуск на этой машине блокируется приватным
`.coach-data/cloud-cutover.json`. Не удаляйте marker, не сбрасывайте журнал и
не запускайте второй платный шлюз: это нарушит единый лимит.

## Секреты

Приватные локальные файлы владельца:

- `.env.coach`: `OPENAI_API_KEY` и серверные параметры.
- `.coach-data/owner-token`: токен владельца, не провайдерский API-ключ.
- `.coach-data/gym-beam-coach-connection.json`: адрес и токен для первого
  подключения телефона. Создаётся скриптом мобильного проекта
  `../gym-tracker-mobile/scripts/create-coach-connection.mjs`.

Реальные значения не печатать и не коммитить. Не передавать секреты аргументами
команд. На Cloudflare они находятся в secret bindings; Wrangler OAuth остаётся
в системном хранилище. При ротации токена нужно обновить подключение телефона,
сохранив объект бюджета и историю расходов.

В APK токен не вшит: после первого подключения он сохраняется через Android
Keystore. Адрес, скрытый токен и кнопка «Забыть подключение» доступны в настройках.
Credentials исключены из экспорта прогресса и Android backup. Удаление подключения
не удаляет дневник. Обычное обновление поверх сохраняет прогресс и подключение.

## Запросы И Бюджет

Текущие модель, версии prompt и тарифы заданы в [provider.ts](src/coach/provider.ts).
Список задач и ограничения проверяются общими схемами `lib/ai-coach`.
Лимит `AI_COACH_MONTHLY_LIMIT_USD` допускает значение больше 0 и не выше 5;
месяц считается в UTC. Он относится к этому журналу по настроенным ценам,
а не ко всем расходам API-аккаунта, хостингу или налогам.

До запроса резервируется стоимость; после ответа учитывается usage. Ошибка
формата ответа не делает уже состоявшийся вызов бесплатным. Неизвестный исход
оставляет резерв, кэш предотвращает повторную оплату одинакового контекста.
Авторизация выполняется до разбора JSON; есть ограничения размера, частоты
и конкурентности. Повторные платные запросы автоматически не запускаются.

Подключение и запрос статуса не вызывают модель. При включённом ИИ открытие
предложения сегодняшней тренировки автоматически запускает его проверку;
это уже платный запрос. Отказ сети или лимит не блокируют локальный дневник.

## Проверки Без Расходов API

Нужны Node.js 24 и pnpm. Из этого каталога:

```powershell
pnpm test:coach
pnpm --dir ../ai-coach-worker test
pnpm --dir ../gym-tracker-mobile test
pnpm --dir ../.. typecheck
```

Тесты используют mock provider, не загружают реальный ключ и не отправляют
личную историю провайдеру. Оплачиваемые evaluation/cloud smoke требуют
отдельного осознанного запуска; существующие отчёты не удалять ради повтора.

Для изолированных проверок используйте временный тестовый журнал, а не
`.coach-data` владельца. Локальная команда `pnpm coach` не предназначена для
параллельного production-запуска после перехода на облако.
